# Simple Cogs

Simple Cogs is a project based upon Cogtimizer, incremented upon it for practicality.

It is a client-side cog board optimization suggestor for Legends of Idleon | The Free IDle MMO. Load your save (paste a config JSON or enter your username), and it rearranges your cogs to maximize build rate, player XP bonus, and flaggy rate. All calculations run in the browser, so there is no server load.

On top of the original optimizer, Simple Cogs shows the current and optimized boards side by side after solving. Click a cog on the optimized board to see where it should come from with an arrow, and mark cogs red as you move them in-game so you can track your progress.
